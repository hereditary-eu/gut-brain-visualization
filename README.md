# Hereditary Brain-gut visualization

## Large data files

Before you run or build this application please add the brain LICA images found here: [https://surfdrive.surf.nl/s/FTqedjssmQmGFdp](https://surfdrive.surf.nl/s/FTqedjssmQmGFdp), in the `src/assets/example-data/neuro` directory.

## Starting the application

To run the visualization on your own system clone this repository and execute the following commands (needs `npm` on your system):

1. `npm install`
2. `npm run dev`

## Model card

The model card for the intended use can be found the [MODEL_CARD.md](./MODEL_CARD.md) file.
